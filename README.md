### 🔬 Featured Computer Vision & Deep Learning Projects

| Project | Highlights & Tech Stack |
| :--- | :--- |
| **[3D Brain MRI Segmentation](https://github.com/cyberpunk92/3d-brain-mri-monai)** | Volumetric neuroimaging analysis & segmentation pipeline using **MONAI**, **PyTorch**, and **NiBabel/SimpleITK** for 3D MRI scans. Implements 3D UNet architectures for anatomical target extraction. |
| **[Skin Lesion Classification](https://github.com/cyberpunk92/skin-lesion-project)** | Deep learning benchmarking on dermoscopic datasets comparing **ConvNeXt**, **Swin Transformer**, and **EfficientNet** backbones using **PyTorch**, **Torchvision**, and **Albumentations**. |
| **[Skin Lesion Grad-CAM (XAI)](https://github.com/cyberpunk92/skin-lesion-gradcam-pytorch)** | Explainable AI (XAI) framework generating class activation maps and gradient-weighted localization (Grad-CAM / Grad-CAM++) to visualize model attention on clinical ROI. |
| **[Practical Machine Learning](https://github.com/cyberpunk92/Practical-Machine-Learning)** | Applied ML suite featuring data preprocessing, feature engineering, and high-performance tabular models using **Scikit-Learn**, **XGBoost**, **LightGBM**, and **CatBoost**. |
